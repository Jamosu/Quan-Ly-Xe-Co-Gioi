# Project documentation

This directory is the durable project memory. Start with `../AI_PROJECT_CONTEXT.md`, then use the documents below.

- `architecture/`: current system and code maps.
- `business/`: behavior and lifecycle rules.
- `development/`: coding, API, database, UI, and test conventions.
- `decisions/`: accepted architectural decisions.

Detailed evidence remains in `.agents/context/`, `backend/prisma/schema.prisma`, backend/frontend source, BRD files, and approved workbooks. Do not duplicate volatile line-level source details here.
